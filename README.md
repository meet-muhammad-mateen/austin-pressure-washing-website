# Austin Pressure Washing & Exterior Cleaning Website

A modern, responsive, high-performance static website built for a professional residential and commercial pressure washing service in Austin, TX.

## ?? Live Demo
You can view the live site on GitHub Pages:  
`https://<your-username>.github.io/<repo-name>/`

## ?? Key Features

* **Interactive Hero Slider:** Smooth, automated image carousel showcasing residential and commercial exterior cleaning work.
* **15 Complete Dedicated Pages:** Full coverage for all primary pressure washing services, process details, before/after showcases, contact forms, and legal documentation.
* **Mobile-First Responsive Design:** Optimized for smartphones, tablets, and desktop displays with smooth navigation.
* **Pure Static Performance:** Lightweight Vanilla JavaScript and modern CSS for instant loading times and zero server overhead.
* **SEO-Optimized Meta & Schema:** Semantic HTML5 structure with targeted service descriptions and metadata.

## ?? Local Development

To view the project locally:

1. Clone or download the repository:
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   ```
2. Navigate to the project directory:
   ```bash
   cd <repo-name>
   ```
3. Open `index.html` directly in your browser or run a lightweight local server:
   ```bash
   # Using Python
   python -m http.server 8000

   # Or using VS Code Live Server extension
   ```
